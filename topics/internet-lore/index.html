10 internet origins questions

1 · Warm-up

In the acronym CAPTCHA, the letter T honors which idea?

  1. Text
  2. Traffic
  3. Turing test
  4. Typing
Show the answer, explanation, and sources

Answer: Turing test. The T in CAPTCHA stands for Turing test.

CAPTCHA expands to “Completely Automated Public Turing test to tell Computers and Humans Apart.” The acronym states the system's purpose directly.

Sources: National Institute of Standards and Technology and National Science Foundation.

2 · Warm-up

Which comedy sketch supplied the term “spam” for unwanted digital messages?

  1. A Second City revue
  2. A Goon Show episode
  3. A Firesign Theatre album
  4. A Monty Python sketch
Show the answer, explanation, and sources

Answer: A Monty Python sketch. The term came from a Monty Python sketch centered on repeated Spam.

In the Monty Python sketch, repeated servings and chants of Spam overwhelm the conversation. Online users adopted the name for unwanted messages that had a similar effect.

Sources: Internet Engineering Task Force and Merriam-Webster.

3 · Core

Which object did Cambridge researchers monitor with the first webcam?

  1. A coffee pot
  2. A server cabinet
  3. A laboratory door
  4. A rooftop weather vane
Show the answer, explanation, and sources

Answer: A coffee pot. The first webcam monitored the Trojan Room coffee pot.

Researchers watched the Trojan Room coffee pot from their desks to avoid an unnecessary trip when it was empty. The feed was later made available on the internet.

Sources: University of Cambridge Computer Laboratory and Guinness World Records.

4 · Core

Ray Tomlinson placed @ inside email addresses mainly because it did what?

  1. Made addresses shorter
  2. Read naturally as “at”
  3. Encrypted the recipient
  4. Marked urgent messages
Show the answer, explanation, and sources

Answer: Read naturally as “at”. The @ sign expressed a user at a host computer.

Tomlinson needed a separator that was not normally used in names. @ was available and locative: it neatly expressed a person “at” a particular computer.

Sources: Internet Hall of Fame and The Museum of Modern Art.

5 · Core

A visitor to the world's first website would mainly learn about which subject?

  1. CERN visitor tours
  2. Particle-collision results
  3. The World Wide Web project
  4. Tim Berners-Lee's biography
Show the answer, explanation, and sources

Answer: The World Wide Web project. The first website explained the World Wide Web project.

Hosted at info.cern.ch, the site described the World Wide Web project and explained how to create and navigate web pages.

Sources: CERN and World Wide Web Consortium.

6 · Core

Scott Fahlman proposed :-) on a 1982 message board to signal what?

  1. The message was finished
  2. The sender was verified
  3. A private reply was wanted
  4. The text was meant as a joke
Show the answer, explanation, and sources

Answer: The text was meant as a joke. :-) marked a message as a joke.

Fahlman suggested the sideways smile as a “joke marker,” with :-( for serious posts. The symbols helped distinguish tone in plain-text discussions.

Sources: Carnegie Mellon University and Guinness World Records.

7 · Core

When Chris Messina proposed using # on Twitter in 2007, what problem was he solving?

  1. Grouping posts by topic
  2. Hiding story spoilers
  3. Tagging people in photos
  4. Shortening long links
Show the answer, explanation, and sources

Answer: Grouping posts by topic. The hashtag was intended to group posts by topic.

Messina suggested using # plus a word to group related messages. Twitter initially declined to build it, but users made the convention spread.

Sources: Smithsonian Magazine and Carnegie Mellon University.

8 · Core

Why did updates to HOSTS.TXT stop scaling as the network grew?

  1. Each host uploaded its own full copy
  2. More hosts downloaded an ever-larger file
  3. Every lookup crossed the network twice
  4. Unused names triggered constant broadcasts
Show the answer, explanation, and sources

Answer: More hosts downloaded an ever-larger file. More hosts had to download an increasingly large central file.

The NIC maintained one HOSTS.TXT file that mapped names to addresses, and hosts downloaded updated copies. As the file and network grew, the traffic and central maintenance became impractical; DNS distributed the work.

Sources: Internet Engineering Task Force and National Academies Press.

9 · Challenge

After an incognito session closes, who may still have observed the sites visited?

  1. Nobody at all
  2. Only another device user
  3. Websites and network providers
  4. Only the browser company
Show the answer, explanation, and sources

Answer: Websites and network providers. Websites and network providers may still observe private-browsing activity.

Private browsing limits history and site data saved on the device. Websites, an employer or school, and the internet service provider may still observe the activity.

Sources: Google Chrome Help and Mozilla Support.

10 · Challenge

UCLA planned to send LOGIN over ARPANET before the remote computer crashed. What arrived?

  1. L
  2. LOG
  3. LOGI
  4. LO
Show the answer, explanation, and sources

Answer: LO. The receiving computer recorded “LO.”

The receiving computer received L and O, then crashed before G arrived. About an hour later, the team successfully transmitted the full word LOGIN.

Sources: UCLA Newsroom and Computer History Museum.
